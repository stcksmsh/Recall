# AIW operating contract

The project persists; agents are replaceable.

- Favor correctness and finished, verified software.
- Continue inspect → implement → build → test → diagnose → fix → verify → checkpoint.
- Start with `aiw load`; retrieve only the task, decision, or source needed next.
- Prefer deterministic tools and authoritative state before inference.
- Diagnose evidence before broadening changes; honor task scope and invariants.
- Completion requires declared verification and a result; persist real blockers.
- Keep decisions and next actions in AIW, not only in conversation.
- Checkpoint so a fresh agent can continue without your history.
- Delegate only independent bounded work; return compact results and evidence.
- Consult local state/source/docs before targeted authoritative external docs.
